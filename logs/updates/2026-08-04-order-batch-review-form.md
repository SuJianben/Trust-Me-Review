# 2026-08-04｜订单批量评价页面

## 本次目标

改善同一订单包含多个商品时的客户评价体验：客户不再需要逐个打开商品链接、重复填写姓名。

## 修改范围

- `src/invitations/InvitationReviewPage.tsx`
  - 任意一个有效商品邀评链接均会加载同一订单内尚可评价的全部商品。
  - 姓名在订单级填写一次；浏览器会在同一订单的其他链接中保留该姓名。
  - 每个商品独立提供星级、可选标题和必填评价内容；一次提交可提交多件已填写内容的商品。
  - 已提交商品显示完成状态，避免重复提交。
- `src/worker.ts`
  - 新增邀评订单读取接口。
  - 邀评提交接口改为订单批量提交，并使用事务锁定订单内商品请求，确保单次令牌提交仍然幂等。
  - 新增不含客户内容的订单批量评价埋点事件 `invitation_review_batch_submitted`。
- `src/features/reviews/schemas.ts`
  - 已购邀评的标题保持可选，评价文字改为至少 1 个有效字符；星级、姓名和评价内容仍为必填。
  - 同一批次禁止重复提交同一个商品请求。
- `src/invitations/invitation-review.css`
  - 增加移动端可用的批量评价表单样式和明确的星级选择状态。

## 影响范围

- 公开商品页评价表单继续保持原有防垃圾规则与最少 10 个字符限制，不受影响。
- 邀评链接仍只允许每个商品提交一次；已提交商品只展示提交状态。
- 不新增数据库表或字段。

## 自检结果

- `npm run typecheck`：通过。
- `npm test -- --run`：8 个测试文件、24 项测试通过。
- `npm run build`：通过，Worker deploy dry-run 通过。
- 已验证邀请批量 schema：标题可为空、评价内容必填、同一商品不可在同一批次重复提交。

## 遗留事项

- 真实邮件投递仍不在 V1 范围内，批量页面由测试邀评链接验证。
