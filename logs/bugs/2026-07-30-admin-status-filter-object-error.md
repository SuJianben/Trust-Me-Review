# 2026-07-30｜后台评论状态筛选显示对象错误

## 现象

在 Reviews 工作台点击 `Pending` 状态 Tab 后，后台出现 `[object Object]` 错误提示，评论筛选未完成。

## 影响范围

- 影响新版后台按状态筛选评论。
- 不影响评论提交、审核、隐藏、删除、邀评和前台展示。

## 根因

评论列表接口把状态、来源、评分和关键词都放在同一个带空值判断的 SQL 条件中。状态筛选加入枚举参数后，数据库查询异常返回了对象结构；前端错误处理又直接将该对象传给 `Error`，最终显示为 `[object Object]`。

## 修复

- 将评论筛选改为按实际存在的条件动态组装 SQL 参数，状态参数显式限定为允许的评论状态。
- 前端 API 层统一将非字符串错误对象转换为可读的通用错误消息。

## 验证状态

- 待部署后在测试店点击 Pending、Published、Hidden、Deleted 进行实际验证。
