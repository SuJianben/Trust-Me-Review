# 2026-07-30｜后台评论状态筛选显示对象错误

## 现象

在 Reviews 工作台点击 `Pending` 状态 Tab 后，后台出现 `[object Object]`，后续显示为通用错误提示；即使筛选结果已正确返回为空列表，红色错误条仍留在页面上。

## 影响范围

- 影响新版后台按状态筛选后的错误反馈。
- 不影响评论提交、审核、隐藏、删除、邀评和前台展示。

## 根因

最初 `[object Object]` 来自前端未把非字符串错误对象转为可读消息。后续通用错误条的真正原因是：`Admin` 组件把 `onClearError={() => setError("")}` 以内联函数传给评论列表；评论列表成功加载后清错会触发父组件渲染，导致该回调引用变化，`useEffect` 又执行一次列表加载。一次筛选因此可能产生两次请求，后一请求失败时会重新显示红色错误条。

## 修复

- 评论筛选按实际存在的条件动态组装 SQL 参数，状态参数显式限定为允许的评论状态。
- 前端 API 层统一将非字符串错误对象转换为可读消息。
- 评论列表成功加载后清除页面级旧错误；若本次请求失败，仍保留本次真实错误。
- 将 `clearError` 改为 `useCallback` 生成的稳定回调，避免清除错误状态后再次触发评论列表加载。
