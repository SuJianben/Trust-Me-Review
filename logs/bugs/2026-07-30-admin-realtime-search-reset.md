# 2026-07-30｜后台评论搜索无法清空

## 现象

商家点击 `Search` 后，输入框和接口请求关键词使用两份独立状态。清空输入框不会清除已生效的请求关键词，导致评论列表无法回到全部结果。

## 影响范围

- 影响评论运营后台的关键词筛选与恢复全部结果。
- 不影响评论审核、状态切换、回复、置顶、删除及前台评论展示。

## 修复

- 移除手动 `Search` 按钮。
- 输入关键词后等待 250 毫秒自动筛选，避免每次按键都发起请求。
- 输入框清空或仅包含空格时，立即清除请求关键词并回到当前筛选条件下的全部评论。

## 验证状态

- 本地：`npm run typecheck`、`npm test`（3 个测试文件 / 8 个测试）、`npm run build` 均通过。
- 已发布 Worker 版本 `303dee98-140c-482d-a453-0a6f4a1384c0`。
- 真实 Shopify 嵌入式后台验证：输入“`双手`”后仅显示匹配评论；清空输入框后回到 `All reviews (1)`，无错误横幅。
- 状态：已修复并完成真实链路验证。
